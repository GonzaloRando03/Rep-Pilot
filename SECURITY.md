# Security Policy

## Supported Versions

Security updates are provided for the actively maintained codebase on a rolling 12-month window.

## Reporting a Vulnerability

Please report security issues privately to: security@granser.com

When reporting, include:

- A clear description of the issue.
- Affected component (rep-pilot-front or rep-pilot-back).
- Reproduction steps or proof of concept.
- Potential impact.

## Response Timeline

- Initial response target: within 72 hours.
- Triage and validation: as soon as possible based on severity.
- Mitigation and fix timeline: communicated after triage.

## Disclosure Policy

Please do not open public issues for security vulnerabilities.
We will coordinate responsible disclosure after remediation.
