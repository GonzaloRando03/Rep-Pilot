# Contributing to Rep-Pilot

Thank you for your interest in contributing.

## Scope

This public repository accepts contributions only for:

- rep-pilot-front
- rep-pilot-back

The private folder is out of scope for public contributions.

## Workflow

1. Open an issue to discuss significant changes before implementation.
2. Create your branch from main using this convention: feature/<short-description>.
3. Keep pull requests focused and small whenever possible.
4. Submit your pull request to main.

## Pull Request Requirements

- Clear description of the problem and solution.
- Linked issue (if applicable).
- Tests added or updated when behavior changes.
- Lint/build pass in the affected project(s).
- Documentation updated when needed.

Conventional Commits are not required.

## Review Policy

- At least one maintainer review is required before merge.
- Maintainers may request changes before approval.
- Maintainers may close stale pull requests that are inactive for extended periods.

## Code Style

- Follow the existing style and conventions of each subproject.
- Do not include unrelated refactors in the same pull request.

## Questions

For general support and contribution questions, contact: support@granser.com
